【一句话】
采购申请（PR）卡在审批上的时间，比后面所有环节加起来都长；把「低值低风险」这一类的审批拿掉，周期能砍掉一大截。
【为什么】
审批是串行人工队列：一级不点，二级永远不动。而审批人对低值申请几乎没有边际信息优势——金额小、品类标准、供应商在合格名录里， 人工审批实际上只能确认「这笔单子看起来正常」。真正的风险控制手段是规则校验 + 事后审计，不是逐单签字。 这就像高速公路的收费站：ETC 车道不是不收费，是把"停车交费"换成了"先通过、后结算、异常再拦"，而且拦的对象从 100% 变成抽检的 10%， 必须靠"事后追责能力"补回来。
【本例证据】
沙盒基线（金额分布由真实采购数据锚定）：PR → PO 中位周期 约 46 小时（接近两个工作日）， 其中两级人工审批按中位数计占约 45%；但它在长尾上占的份额更大 —— 遭遇积压或驳回返工时，审批会反复串行叠加，把 P90 推到 100 小时以上（四天多）。 低值低风险 PR 占全部申请量的约 三分之一（33%）（由真实金额分布与品类风险分级推算）。
【怎么改】
实验组改为：金额 ≤ 阈值 且 品类风险=低 的 PR，由规则引擎做预算科目余额、合格供应商名录、重复采购三项校验， 约 1 小时内自动放行；其余 PR 维持原两级审批。同时对该通道增加事后抽检兜底。对照组完全不变。

实验假设与决策规则（事前冻结）

先写死判据，再看数据 —— 这是整套流程里最重要的一条纪律。

H1（主假设）：分级授权可显著降低 PR→PO 周期。
判据：对数尺度几何均值比 < 1 且 p < 0.05，95% CI 上限 < 1。
H2（效率假设）：目标人群 48 小时内完成率显著提升。
判据：绝对提升 > 10pp 且 p < 0.05。
H3（护栏假设）：不得以牺牲管控换取速度。
判据：审计异常率上升 < 1.0pp（非劣界），价格偏差上升 < 1.5pp。任一越界 → 不上线。
决策规则（三选一，不允许事后挑选口径）
① H1+H2 显著 且 护栏未越界 → 有条件放量（限金额阈值 + 强制抽检）
② H1 显著 但护栏越界 → 先补管控再放量
③ H1 不显著 → 不上线，转做流程节点拆解诊断

为什么这件事值得做实验，而不是拍脑袋上线

① 有明确的可比反事实

同一批采购员、同一套系统、同一时间段，随机让一部分 PR 走新通道。除了策略本身，其他条件都一致 —— 这是因果推断的最低门槛。

② 效应量小、噪声大

周期是重尾分布，个别大额 PR 的驳回返工能拉高整周均值。不上随机化、不做方差缩减，凭"上线前后对比"根本分不清是策略有效还是这周运气好。

③ 有真实的下行风险

放宽审批必然抬高"放水"概率。实验的价值不只是证明收益，更是把代价量出来——审计异常率涨了多少、抽检能不能兜住。

真实数据用在哪、没用在哪

这两份数据都是政府/多边机构的合同授予记录，不能直接当作某家企业的 PR 流水： 没有 PR 级审批时间戳，量级也完全不同（联邦合同多在千万美元级）。

所以本沙盒的做法是：用真实数据锚定"形状"，用企业场景重定"尺度"—— 金额的对数正态离散度、品类构成、供应商集中度、合同期限分布、竞争方式构成取自实测； 金额中位数按中型制造企业采购量级重设，且该映射在下方映射表中逐条标出。

没有公开数据集包含"PR 审批各节点耗时"，因此流程耗时部分由带真实结构特征 （重尾、周末低谷、积压放大、按风险等级分化）的生成过程仿真，不是实测。这一点必须说清楚，不能含糊。

设计要素一览

指标树：一个主指标，两个次指标，三个护栏

主指标只有一个。指标一多，就等于没有判据。

层级指标定义判据
主PR→PO 周期PR 创建时刻 → PO 签发时刻（小时）几何均值比 < 1，p<0.05，CI 上限 < 1
次48h 完成率周期 ≤ 48h 的 PR 占比绝对提升 > 10pp
审批驳回率被人工驳回的 PR 占比不上升（诊断用）
护栏事后审计异常率拆单、超预算、指定供应商的流出比例上升 < 1.0pp（非劣）
采购价格偏差成交价相对品类基准价的偏离上升 < 1.5pp
紧急/围标采购占比绕过正常流程的采购占比不显著恶化
为什么主指标用几何均值而不是算术均值。 采购周期是典型重尾分布（真实合同数据确认：对数标准差 0.9 量级，偏度极高）。 算术均值会被少数超长周期 PR 带跑，中位数又对尾部不敏感。 几何均值 = 对数尺度上的均值，既抗尾部拉拽，又能直接解释成"典型周期的比值"。这是采购/履约类指标的行业惯例口径。

随机化与分流方案

随机化单元的选择，决定了这个实验能不能被正确解释。

随机化单元
采购申请（PR）单条记录
分流时机
PR 提交时即时分配，策略贯穿该 PR 全生命周期
分层变量
品类（6）× 金额档（3）= 18 层，层内 1:1 随机
分析口径
ITT（意向治疗）：按初始分配组分析，不按实际是否走了自动通道
为什么按 PR 而不是按"采购员/部门"随机化？ 按人随机会出现 溢出效应：同一个采购员同时处理新旧两套流程，会把新流程的习惯带到对照组，稀释效应估计。 按 PR 随机则要求系统必须在单号层面无差别执行策略，且不存在跨 PR 的依赖 —— 本例满足（审批是逐单的）。
但代价是：同一采购员的对照组 PR 仍会被"他这次不用签字了"这件事影响，属于轻度污染。诊断页会给出按采购员聚类的稳健标准误作为补充。
ITT 与 CACE。只有约 37% 的 PR 会被策略实际覆盖（低值 + 低风险 + 规则校验通过）。 全体口径（ITT）看到的是被稀释后的效应，比"被覆盖人群上的真实效应"小得多。 只报 ITT 会低估价值，只报覆盖人群又会高估推广收益 —— 两个口径都要报，并在决策页写明适用范围。

分组样本量累积（SRM 监控）

分流比例是实验的生命线。比例失配通常意味着分流代码有 bug，此时任何显著性结论都不可信。

主指标多方法对照

同一个效应，用四种方法算，看结论是否一致。口径之间打架时，先查数据再下结论。

CUPED 方差缩减

用"该品类×金额档的历史平均审批时长"作为协变量，在不增加样本的前提下压缩方差。

分布诊断：为什么必须在对数尺度上做检验

如果原始尺度上的偏度与峰度爆表，t 检验的正态假设就站不住。

异质性分析（CATE）：效应集中在谁身上

全样本平均效应会掩盖结构性差异。森林图显示各子群的对数尺度效应与 95% CI，右侧为"策略覆盖率"。

护栏指标与非劣检验

速度提升如果以管控失守为代价，这个实验就是失败的。下面每一项都必须是"没有显著恶化"。

多重比较校正

次指标与护栏一起检验了多次，不做校正就等于偷偷放水。
