# 采购流程 A/B 实验沙盒 · PR 审批分级授权

> 一个只聚焦**一个采购环节**的随机对照实验沙盒：把「低值低风险采购申请的串行人工审批」
> 换成「规则引擎自动放行 + 事后审计」，并用规范的 A/B 方法论把它验证清楚。

---

## 一、这份交付物回答什么问题

**唯一问题**：把低值、低风险采购申请的两级串行人工审批拿掉，换成规则引擎自动放行，
到底能不能真正缩短采购周期？代价是什么？

不做供应链全景看板。链路只动一个节点：

```
需求提出 → 创建 PR → 【PR 审批 ✦ 本实验唯一干预点】 → 询价/定点 → PO 签发 → 收货 → 三单匹配 → 付款
```

| 组别 | 策略 |
|---|---|
| 对照组 A | 所有 PR 走 直属主管 → 采购经理 两级串行人工审批 |
| 实验组 B | `金额 ≤ 阈值 且 品类风险 = 低` 的 PR，由规则引擎做「预算科目余额 / 合格供应商名录 / 重复采购」三项校验后自动放行；其余 PR 维持原流程。另加事后抽检 |

**沙盒默认结果**（种子 20260、日均 380 条、28 天、阈值 ¥50,000）：

| 指标 | 对照组 A | 实验组 B | 变化 |
|---|---|---|---|
| PR→PO 几何均值周期 | 47.1 h | 33.1 h | **−29.6%**（95%CI [−31.9%, −27.4%]） |
| 48h 完成率 | 53.9% | 64.6% | +10.6 pp |
| 事后审计异常率（护栏） | 1.11% | 1.89% | +0.78 pp（界 1.0 pp，未越界但已需监控） |
| 采购价格偏差（护栏） | +0.27% | +1.42% | +1.15 pp（界 1.5 pp，未越界但已需监控） |

**结论：有条件放量上线** —— 限金额阈值、限低风险品类、全量留痕、设熔断条件。

## 二、怎么用

直接双击 `index.html` 打开即可（纯前端、零依赖、无需服务器）。

六个页签：

| 页签 | 内容 |
|---|---|
| 1 业务与聚焦点 | 为什么选这个环节、四段式说明、一页速查表、事前冻结的假设与决策规则 |
| 2 数据源与基线 | 真实数据来源、金额分布及其**对数正态假设检验**、供应商集中度、品类构成、参数来源映射表 |
| 3 实验设计 | 指标树、随机化与分流方案、样本量规划器、**护栏指标样本量规划器**、A/A 验证、事前检查清单 |
| 4 沙盒运行 | 参数面板 + 逐日回放动画 + KPI + 累积效应图 + 序贯检验轨迹 + 分布对照 + SRM 监控 |
| 5 统计诊断 | 多方法对照、CUPED、分布诊断、异质性森林图、护栏非劣检验、BH 多重比较校正 |
| 6 决策与规范 | 判据核对表、落地条件、年化收益估算、A/B 规范清单、已知局限、下一步 |

### 值得动手试的几个旋钮

| 操作 | 会看到什么 |
|---|---|
| 把「自动放行金额阈值」从 ¥5 万拉到 ¥100 万 | 主指标继续变好（周期比 0.70→0.62），但**护栏先出问题** —— 价格偏差越过 1.5pp 非劣界，结论从「有条件放量」变成「先补管控」 |
| 把「事后抽检比例」从 10% 拉到 40% | 护栏点估计几乎不动 —— 覆盖率就是发现率的上限，抽检兜不住 |
| 把「实验组流量偏移」拉到 ±3% | SRM 检验报警拦截，实验被判定无效 |
| 把「实验天数」降到 7 天 | 主指标仍显著（效应大），但护栏指标完全测不出来 |
| 点「运行 A/A 验证」 | 假阳性率：单次检验 5.3% / 每天偷看不校正 27.7% / OBF 序贯边界 5.0% |
| 换「随机种子」 | 结论稳定（已把层效应固定为零均值表，基线不随种子漂移） |

## 三、数据从哪来

两份**通过官方 API 实时抓取**的公开真实采购数据。抓取脚本与原始数据在 `../pipeline/`。

| 数据源 | 用途 | 许可 |
|---|---|---|
| **USASpending.gov** `/api/v2/search/` | 联邦采购合同授予数据：分带计数（金额密度）+ 聚合端点（供应商 / PSC / NAICS / 机构 / 国家） | 公有领域 |
| **World Bank Procurement Notices** `search.worldbank.org/api/v2/procnotices` | 采购方式构成 | CC BY 3.0 IGO |

**采集规模**：43 个对数金额分带 × FY2023 + FY2025 两个财年，逐带调用计数接口得到
**3,818,521 条**真实合同的金额分布（覆盖 $1,000 – $37M 区间，占该期间全部合同动作的 35.5%）；
聚合端点另取 500 家供应商、40 个 PSC 品类、40 个 NAICS 行业。

### 真实数据用在哪、没用在哪 —— 这一节必须看

**用了**：金额分布的**形状**（直接抽经验分布，不做参数化拟合）、品类与供应商构成、采购方式构成。

**没用**：
- 没有 PR 级审批时间戳 → 流程耗时部分由带真实结构特征（重尾、周末低谷、积压放大、
  按风险等级分化）的**生成过程仿真**，不是实测。
- 量级不可直接套用 → 只做一次**显式可追溯的尺度平移**（×3.2006：真实中位数 $5,624 → 沙盒中位数 ¥18,000），
  并在真实分布 P99 处截断。

### 一个实测结论：这笔钱的分布不是对数正态

按四分位距反推 σ=1.816，预测 P99 只有 $384,268，而实测 P99 是 $2,998,077 —— **低估 7.8 倍**；
改用对数空间最小二乘拟合（σ=4.10），尾部又虚高约 4,898 倍。两个方向都失败。

小额区间的偏差同样明显：$1,000–$1,500 这一带，对数正态只预测出实测计数的 **38%**。

→ 所以沙盒**不引入任何参数化假设**，金额直接从这个经验分布抽样。
第 2 页有分带偏差诊断图可以直接看。

## 四、方法论要点（可直接当团队 SOP）

**事前**
- 主指标唯一且冻结口径：PR→PO 周期，**对数尺度几何均值比**（重尾数据用算术均值会被尾部带跑）
- 护栏指标设**非劣界**而非显著性判据：审计异常 < 1.0pp、价格偏差 < 1.5pp
- MDE 与样本量开跑前算好：要检出 12% 的周期改善，每组需 346 条、合计 692 条（约 1.8 天）
- **A/A 验证过分析管线**：单次检验假阳性率 5.3%，接近 5% 才算可信
- 停止规则事前确定，不允许事后改

**事中**
- SRM 每日监控，两级判定：p<0.001 或偏离 >2% → 硬失败；p<0.01 → 告警
- 序贯检验用 **Lan-DeMets O'Brien-Fleming 消耗函数 + Armitage–McPherson 精确积分**求临界值，
  不是 `1.96·√(K/k)` 近似。实测整体第一类错误率 5.0%（K=28）、4.0%（K=56）

**事后**
- 同一效应用四种方法算，口径一致才下结论（对数 t / 原始 t / Bootstrap 中位数 / CUPED）
- **CUPED 压方差**：用「同品类同金额档的历史平均审批时长」作协变量，实测 ρ=0.570、方差缩减 34.5%，
  等效于凭空多出 53% 的样本
- **ITT 与 CACE 都报**：覆盖率仅 33%，ITT 显示周期降 30%，被覆盖人群实际降 66% —— 差一倍以上，不能只报一个
- **异质性（CATE）**：效应集中在低风险品类（0.457×）与覆盖人群（0.332×），高风险品类无变化
- **BH 校正**：次指标与护栏一起检验了 6 项，不做校正等于偷偷放水

### 最反直觉的一条发现

> **主指标 1 天就能测出来，护栏指标要跑 122 天。**
>
> 「审计异常率从 1.20% 涨到 1.50%」这种量级的变化，每组要到 **23,228 条**才有 80% 把握检出，
> 而主指标只要 **45 条**。**相差 516 倍。**
>
> 结论：护栏不能用「统计显著」当判据。正确做法是 ① 只看方向与非劣界；
> ② 用持续监控 + 熔断替代一次性实验结论；③ 一旦点估计越界，宁可信其有，不等样本量攒够。

## 六、已知局限（诚实清单）

1. **流程耗时是仿真，不是实测。** 公开数据没有 PR 级审批时间戳。落地前必须用企业内部 OA/采购系统日志重新标定。
2. **无长期效应评估。** 4 周实验看不出「申请人是否会把大额采购拆成小额来钻阈值空子」。
3. **ITT 低估价值，CACE 高估可推广性。** 阈值上调后边际人群风险画像更差，效应与护栏都不能线性外推。
4. **轻度溢出污染。** 同一采购员同时处理两套流程，可能把新流程习惯带入对照组。
5. **护栏测量误差。** 10% 抽检最多只能发现 10% 的异常，真实异常率必然被低估。把抽检拉到 40% 也几乎不改变点估计。
