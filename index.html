采购流程 A/B 实验沙盒
PR 审批分级授权

把「低值低风险采购申请的串行人工审批」换成「规则引擎自动放行 + 事后审计」， 并用规范的 A/B 方法论把这个改动验证清楚。

数据来自两份公开真实采购数据源 —— USASpending.gov 的 381.8 万条联邦合同金额分布、 World Bank 的采购公告构成。流程耗时部分为结构化仿真，已在文末明确标注。

需求提出 → 创建 PR → 【PR 审批 ✦ 本实验唯一干预点】 → 询价/定点 → PO 签发 → 收货 → 三单匹配 → 付款

02三条最值得记住的发现

1

效果确实存在，而且很大

周期从 47.1 小时降到 33.1 小时，降幅 29.6%。这不是"审批快了一点"，而是有三分之一的采购申请当天就能走完流程。

2

护栏指标根本测不动

主指标只要 45 条样本就有 80% 把握检出效应，护栏要 23,228 条，相差 516 倍。
按 380 条/天算：主指标 1 天可测，护栏要 122 天。
→ 护栏不能用"统计显著"当判据，只能用方向 + 非劣界 + 持续监控 + 熔断。

3

抽检比例救不了你

把事后抽检从 10% 拉到 40%，护栏点估计几乎不动。因为抽检覆盖率就是异常发现率的上限 —— 抽 10% 最多只能看见 10% 的问题，真实异常率必然被系统性低估。

数据源用途许可
USASpending.gov
/api/v2/search/		 43 个对数金额分带的真实计数 → 还原金额密度；供应商 / PSC / NAICS 聚合 公有领域
World Bank
Procurement Notices		 世行采购公告 1,000 条，用于采购方式构成 CC BY 3.0 IGO

采集规模：43 个金额分带 × 2 个财年（FY2023 / FY2025）逐带调用计数接口，得到 3,818,521 条真实合同的金额分布，覆盖 $1,000 – $37M 区间，占该期间全部合同动作的 35.5%。

⚠ 用在哪、没用在哪，必须分清楚。
用了：金额分布的形状（直接抽经验分布）、品类与供应商构成、采购方式构成。
没用：公开数据里没有 PR 级审批时间戳。流程耗时部分由结构化仿真生成，不是实测。 量级不可直接套用，只做了一次显式可追溯的尺度平移（真实中位数 $5,624 → 沙盒 ¥18,000），并在 P99 处截断。
落地前必须用企业内部 OA / 采购系统日志重新标定。

一个实测结论：这笔钱的分布不是对数正态

这一点决定了沙盒的抽样方式，值得单独说：

拟合方式预测 P99实测 P99偏差
四分位距反推 σ$384,268$2,998,077低估 7.8 倍
对数空间最小二乘虚高约 4,898 倍—高估 4,898 倍

两个方向都失败。小额区间同样明显：$1,000–$1,500 这一带，对数正态只预测出实测计数的 38%。 所以沙盒不引入任何参数化假设，金额直接从经验分布抽样。

05方法论要点（可直接当团队 SOP）

事前

  • 主指标唯一且冻结口径：PR→PO 周期，用对数尺度几何均值比（重尾数据用算术均值会被尾部带跑）
  • 护栏指标设非劣界而非显著性判据：审计异常 < 1.0 pp、价格偏差 < 1.5 pp
  • MDE 与样本量开跑前算好：要检出 12% 的周期改善，每组需 346 条、合计 692 条（约 1.8 天）
  • A/A 验证过分析管线：单次检验假阳性率 5.3%，接近 5% 才算可信
  • 停止规则事前确定，不允许事后改

事中

  • SRM 每日监控，两级判定：p<0.001 或偏离 >2% → 硬失败；p<0.01 → 告警
  • 序贯检验用 Lan-DeMets O'Brien-Fleming 消耗函数 + Armitage–McPherson 精确积分求临界值，不是 1.96·√(K/k) 近似。实测整体第一类错误率 5.0%（K=28）、4.0%（K=56）

事后

  • 同一效应用四种方法算，口径一致才下结论（对数 t / 原始 t / Bootstrap 中位数 / CUPED）
  • CUPED 压方差：用「同品类同金额档的历史平均审批时长」作协变量，实测 ρ=0.570、方差缩减 34.5%，等效于凭空多出 53% 的样本
  • ITT 与 CACE 都报：覆盖率仅 33%，ITT 显示周期降 30%，被覆盖人群实际降 66% —— 差一倍以上，不能只报一个
  • 异质性（CATE）：效应集中在低风险品类（0.457×）与覆盖人群（0.332×），高风险品类无变化
  • BH 校正：次指标与护栏一起检验了 6 项，不做校正等于偷偷放水

07已知局限（诚实清单）

  1. 流程耗时是仿真，不是实测。公开数据没有 PR 级审批时间戳。落地前必须用企业内部 OA / 采购系统日志重新标定。
  2. 无长期效应评估。4 周实验看不出「申请人是否会把大额采购拆成小额来钻阈值空子」。
  3. ITT 低估价值，CACE 高估可推广性。阈值上调后边际人群风险画像更差，效应与护栏都不能线性外推。
  4. 轻度溢出污染。同一采购员同时处理两套流程，可能把新流程习惯带入对照组。
  5. 护栏测量误差。10% 抽检最多只能发现 10% 的异常，真实异常率必然被低估。把抽检拉到 40% 也几乎不改变点估计。
